# Architektur (arc42)

Die maßgebliche Produktarchitektur ist im **openEduSuite**-Repo als
[arc42 + C4](../openEDU/docs/arc42/README.md) dokumentiert; die UDC-Ausprägung unter
[openEduSuite-production/docs/arc42](../openEDU-production/docs/arc42/README.md).

Dieses Repo (**openEDU-spec**) hostet spezifikations-/vertragsnahe Inhalte
(Docusaurus, Spec-Kontrakte) und ergänzt die Architektur-Doku um Spec-Ebene.
